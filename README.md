# 轻桥 LanBridge 2.1

电脑和电脑、电脑和手机之间，**复制的东西自动过去**：这边复制文字、截图、文件，那边直接粘贴。拖个文件到设备上就发过去。

- 电脑：一个 `LanBridge.exe`，双击就用，不用安装（Windows 10/11 自带的 .NET 4.8 就够）。
- 手机：iPhone、安卓都行，**不用装 App**，用相机扫一下电脑上的二维码就连上了。

## 第一次用（每台设备只做一次）

**连电脑**：两台电脑都打开轻桥。另一台会自动出现在“附近的电脑”里 → 点 **连接** → 到那台电脑上点 **允许**。

- 不用输地址，不用复制邀请码。两边会显示同一个 6 位核对码，一样就说明连的是对的电脑。
- 有第三台、第四台电脑时，只要和组里**任意一台**连一次，就和所有电脑互通。
- 那台电脑还没有轻桥：在它的浏览器打开 `http://本机地址:49321/get` 就能下载。
- 第一次打开时 Windows 会问“是否允许访问网络”，点 **允许**。点错了可以在 设置 → 网络 → **放行**。

**连手机**：点 **添加设备**，用手机相机扫二维码，点弹出的链接，就连上了。在网页里点“分享 → 添加到主屏幕”，以后像 App 一样一点就开。

**不在同一个网络**（家里 ↔ 公司，手机用流量）：在 **添加设备 → 不在同一个网络？** 里能看到本机的连接码（8 位；用临时中转或自己的中转时后面带“@中转地址”，对方整个粘贴进去就行，不用先设置中转），在另一台电脑上输入它，再到这边点 **允许**。以后两台在哪个网络都会自动连上：能直连就直连，连不上就经中转。设置了中转后，手机扫的二维码也是中转地址，用流量、在别的 Wi-Fi 都能用。

## 之后的日常（什么都不用点）

| 你做的事 | 会发生什么 |
|---|---|
| 在一台电脑上复制文字 / 截图 / 在资源管理器复制文件 | 其他电脑的剪贴板马上就是它，直接 Ctrl+V |
| 把文件或文件夹拖到窗口里的某台设备上 | 发过去，存到对方的“下载\轻桥”文件夹（文件夹自动打包成 zip）；对方不在线就排队，上线后自动送达 |
| 在文件上右键 → 发送到 → 轻桥 | 同上（只有一台电脑在线时直接发，不用选） |
| 手机网页里粘贴文字 / 选照片 | 进电脑剪贴板，也同步到其他电脑 |
| 电脑上复制，手机网页开着 | 手机网页立刻显示，点“复制到手机” |
| 想找手机以前发来的文字、照片 | 点电脑窗口里的手机卡片（或“动态”旁的“手机发来的内容”），能搜索、再复制 |
| iPhone 背面轻点两下（设置一次快捷指令，见手机网页） | 哪边有新文字就同步到另一边 |
| 电脑重启、换了 IP、换了 Wi-Fi | 自动重新连上 |
| 笔记本从公司带回家 | 自动从“经中转”换成直连（反过来也一样） |

关掉窗口不会退出，轻桥在右下角托盘里继续运行（约 50 MB 内存）。开机自动启动、右键“发送到”默认打开，可以在设置里关。

## 安全和隐私

- 电脑之间：配对时用 ECDH 交换密钥，之后所有请求都签名，**文字、图片、文件都加密传输**（AES-256 + HMAC 校验）。不在同一组的设备拿不到任何内容。
- 被移出设备组的电脑会收到通知，换新密钥，不再收发。
- 密码管理器等标记了“不要同步”的复制内容会被跳过。剪贴板文字只在内存里，不写盘。
- 手机网页在同一个 Wi-Fi 里走局域网 HTTP；经中转时走 HTTPS 到中转，中转再转给电脑。
- **中转**只转发、不存东西。电脑之间的内容在电脑上就加密好了，中转看不到；手机经中转的内容中转能看到（所以中转要放在自己的服务器上）。中转只认每台电脑自己的轮询密钥，别人冒充不了。
- 设置保存在 `%LOCALAPPDATA%\LanBridge`，用当前 Windows 账户加密。

## 目前做不到的

- **小云**：常驻中转上的小文件池（1 GB，满了先删最早的）。主界面多一张“小云”卡片，拖文件进去，组里的电脑都能下载；每个文件有链接，手机或别人在浏览器里打开就能下载。文件在电脑上加密后才上传，服务器只有密文。
- 不在同一个网络时要经中转，两种：**常驻中转**（一台服务器，地址固定；自己的服务器一行命令装好，见 [relay/README.md](relay/README.md)）或 **临时中转**（组里一台电脑经 Cloudflare 免费临时隧道当中转，免安装，但这台要开着、重启后地址会变，国内有时连不上 Cloudflare）。经中转时复制的图片、文件超过 20 MB 不自动同步，主动发的单个文件默认不超过 300 MB。
- iPhone 不能在后台自动监听剪贴板（系统限制）：手机上复制的东西不会自己过去，要在轻桥网页里粘贴（经中转打开时点“发送手机剪贴板”），或设置一次“轻点背面”，以后复制完轻点两下；iOS 17 以上还能设成离开微信等 App 时自动发送（手机网页的设置说明里有）。
- 两台电脑之间自动同步的文件默认单次不超过 200 MB，更大的拖到设备上发。

## 从 1.5 升级

1.5 和 2.0 不互通，所有电脑都要换成 2.0。先在托盘右键退出 1.5，再运行 2.0 的 `LanBridge.exe`；手机重新扫一次码。1.5 的“轻点背面”快捷指令还能用，只要把授权码换成手机网页里显示的新授权码；也可以按网页说明重建一个更简单的（只要三个动作）。

