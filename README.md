# 轻桥 LanBridge 1.5

Windows 与 Windows、Windows 与 iPhone 之间共享文字、图片和文件。电脑日常运行一个 EXE；iPhone 使用 Safari 和系统快捷指令，不安装额外手机 App。

[下载 Windows 1.5 试用版](https://github.com/snowylove666-tech/lanbridge/releases/tag/v1.5.0) · [查看源码](https://github.com/snowylove666-tech/lanbridge)

当前版本仍在试用：跨网临时服务尚未通过当前测试网络的真实收发验证，iPhone 和两台物理电脑的实际粘贴表现仍需确认。验证范围见 [TESTING.md](TESTING.md)。

## 这一版的操作方式

设备页只保留 **连接电脑／连接手机** 两个入口。你不需要判断有线、Wi-Fi、热点或多级路由器是否属于同一网络。电脑邀请会带上多个可尝试的地址，程序先试直连，邀请中有临时互联网入口时再尝试它。

- **设备**：添加设备、粘贴邀请、点击最近电脑重连。
- **剪贴板**：分别控制文字自动同步、图片／文件自动同步。
- **文件**：选择收件设备，粘贴、拖入或选择文件；查看接收确认和保存位置。
- **设置**：管理历史电脑、已配对设备、暂停及连接检查。

临时入口创建、地址检测通过、对方实际连接分开显示。本机公网自测失败后会继续自动检查，并保留临时入口等待另一台设备尝试；不会要求因一次自测失败反复点击开启。公共服务本身仍可能不可达。

## 升级

先在托盘右键 **退出轻桥**，再替换 EXE。关闭窗口只会留在托盘。

原目录升级保留 **Data** 和 **Received**，只替换 EXE。图片／文件剪贴板需要两台电脑都使用 1.5；旧手机配对和文字快捷指令继续兼容。适用于 Windows 10/11 和系统自带的 .NET Framework 4.8。

## 连接两台电脑

1. 两台电脑都运行轻桥。一台在 **设备 → 连接电脑** 查找并选择另一台，再点连接；对方核对识别号允许一次。
2. 没找到时，在另一台进入 **创建／加入邀请 → 我来发邀请 → 复制连接邀请**。
3. 把整段邀请交给发起连接的电脑，在 **连接电脑** 输入框粘贴并连接。也可以使用 **我有邀请，加入连接**。电脑不需要扫码。
4. 程序尝试邀请里的直连地址。只需一端发起，连接后可以双向传输。

邀请包含五分钟内一次有效的配对凭据，只发给要连接的人；重复复制有效邀请不会使前一份失效。发现电脑只提供入口，不会自动授予共享权限。

连过的电脑会出现在 **设备 → 最近电脑**，点击即可复用保存的授权重连。更多记录在 **设置 → 历史电脑**，可双击或点重新连接；最多保存 12 条。记录仅包含本机成功主动连接过的电脑，手机授权列表不等于可从电脑唤醒手机。地址变化、授权被撤销或临时入口过期时，仍需新邀请。

### 直连没成功

在提供邀请的一台选择 **准备互联网入口**，出现“临时入口已创建”后，重新复制邀请给对方。另一台加入时先试直连，再试这个入口。双方都不需要自备服务器、域名或 Cloudflare 账号。

“入口已创建”只表示有了临时地址；“本机检测已通过”表示本机能访问该地址；实际连接成功仍以对方设备的通信结果为准。若显示本机公网自测未通过，可以让另一台设备尝试邀请，结果尚未确认时不要当作已连通。

互联网入口使用 Cloudflare Quick Tunnels。首次开启下载约 53 MB 官方模块并校验 SHA-256，通道三十分钟后关闭；重开会换地址，关闭会撤销临时授权。单文件跨网上传限 90 MB，内容经过 Cloudflare，当前没有端到端内容加密。该服务官方定位为测试／开发用途，没有可用性保证；本版不能承诺所有网络稳定连接。[Cloudflare 说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

### 家里有两台路由器

例如主机接光猫 A，笔记本和手机接路由器 B。是否处于同一网段取决于 B 的工作方式和隔离设置；不应让使用者先回答这个问题。先让接在 B 的笔记本使用主机创建的邀请，程序会尝试主机的实际地址。多级路由下“搜不到”不一定意味着地址不能访问，直连仍取决于实际路由和防火墙。程序不会更改路由器设置。

## 复制文字、截图和文件

电脑连接后，在两端 **剪贴板** 页开启相应选项一次：

| 开关 | 之后怎样用 |
|---|---|
| 自动同步文字 | 复制新文字，另一台直接 Ctrl+V |
| 自动同步图片和复制的文件 | 截图、复制图片或在资源管理器复制文件，另一台在支持图片／附件／文件的应用粘贴 |

图片／文件自动同步默认关闭。开启后，新复制内容会发送给已连接电脑，不自动放进手机共享区。目标应用是否接受粘贴取决于该应用支持的格式；复制资源管理器里的图片文件按文件附件处理。

不想开启自动同步时，去 **文件** 页选择收件设备，复制图片或实际文件后点 **粘贴并发送**，或在本页按 Ctrl+V。接收方没有开启附件同步时，文件仍保存到 **Received**；在文件列表选择记录、点 **复制选中内容**，即可自行粘贴。也可继续使用选择文件、拖入窗口。

多文件组全部保存后才尝试写入接收方剪贴板；其中一项未到齐，不会把半组当成完成。文件已经保存和剪贴板已经写入分别显示。等待期间若本机有更新的复制，旧组不会覆盖它。剪贴板被占用会重试；损坏图片保留为文件并说明原因。

支持截图／位图／PNG 和资源管理器的实际文件列表，一次最多 32 个文件，单文件最大 1 GB；图片剪贴板限 64 MB、4000 万像素。邮件软件内部尚未保存的虚拟附件需先保存或拖出为实际文件；文件夹先压缩 ZIP。图片和文件接收不代表已经在目标应用中粘贴。

## iPhone 怎么用

首次：打开 **设备 → 连接手机**，在 iPhone Safari 输入显示的固定地址，点连接，在电脑核对识别号允许一次。同热点可以直接输入，不必扫码；地址解析不通时展开备用 IP。

文字省操作：在手机网页 **设置与帮助 → 设置轻点背面**，按显示的地址和授权头创建一个 **轻桥同步** 快捷指令，再绑定 **设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下**。首次运行建立基线。

- 电脑复制 → 手机轻点背面 → 在原 App 粘贴。
- 手机复制 → 同样轻点背面 → 电脑 Ctrl+V。
- 两边都有变化时，本次手机新内容优先，不弹方向选择。

首次仍需手动创建快捷指令，本版没有签名的一键导入包。iPhone 无法由本程序后台持续监控剪贴板；真实复制时间也不可得，不能严格保证所有交叉操作都按实际“后复制者优先”。自动接收处理两分钟内的新文字，超时请重新复制；共享文字预览保留十分钟。原快捷指令处理文字，不能因电脑支持图片就自动同步手机图片剪贴板。

图片和文件在手机网页 **文件** 页上传、下载。主动粘贴是否能交给网页取决于 iOS／Safari 和来源应用；系统没有提供可粘贴的文件时，使用选择照片／文件。下载后在 Safari 下载列表或“文件”App 查看。网页打开不代表后台自动接收；临时互联网地址也不会自动替换原背面指令的地址。

## 附近没有 Wi-Fi 或互联网

**两台 Windows 都有蓝牙**：在 **连接电脑 → 蓝牙传文件** 打开系统文件传输。一端选接收，另一端选发送，按系统提示配对和选文件；不需要互联网。这是系统手动传文件入口，尚未接入轻桥的自动剪贴板同步或接收记录。[Microsoft 操作说明](https://support.microsoft.com/en-gb/windows/hardware/bluetooth/send-and-receive-files-over-bluetooth-in-windows)

iPhone 不能直接使用这个 Windows 通用蓝牙文件通道；可通过个人热点或其他可达网络使用网页和快捷指令。蓝牙配对本身也不表示已经建立可供网页使用的 IP 网络。[HP 设备兼容说明](https://support.hp.com/rs-en/document/ish_4464815-3666310-16)

## 文件与结果

| 收件位置 | 保存及确认 |
|---|---|
| 当前连接的电脑 | 发给对方，自动保存到对方程序旁的 Received |
| 已授权的电脑 | 放入专属队列，等待接收确认后标记送达 |
| 手机／浏览器共享区 | 放入 Data/Outbox；手机打开网页下载，不代表已保存到手机 |

电脑私人接收文件不向其他设备共享。文件不会自动打开。目录合计限 5 GB、500 条记录；暂不支持断点续传。发送或上传结果未确认时，先检查对方接收记录，避免重复发送。移除接收记录保留原文件，移除发送记录会删除 Outbox 副本。

连接问题看 **设备** 页具体状态，或 **设置 → 刷新地址并检查**。文字和附件分别看 **剪贴板** 页开关及结果；文件先看 **文件** 页，再打开接收文件夹。设置中的暂停会停止互传。

## 隐私与运行

自动共享会包含新复制的敏感内容，按需开启。局域网是带鉴权的 HTTP 明文，只用于可信网络，不要把端口直接转发到公网。配对及历史凭据由当前 Windows 用户 DPAPI 加密保存；剪贴板文字正文只在内存，接收文件和截图临时副本不做磁盘加密。邀请包含配对密钥，不能当作普通公开链接。

关闭窗口后驻留托盘，右键可退出。Alt+Shift+C 手动共享文字，Alt+Shift+O 打开窗口；登录启动和文件右键入口按需启用。“最近结果”只在本次运行保存状态，不记录剪贴板正文或配对密钥。

验证结果与真机限制见 **TESTING.md**，实现说明见 **DESIGN.md**。程序未商业签名，Windows 可能显示未知发布者。

构建：`./build.ps1 -ExecutableName LanBridge-v1.5.0.exe`。默认 TCP 49321，可用 `--port` 指定。用户无需 Node、Python、Electron 或 .NET SDK。
