设置轻点背面 · 日常少操作

电脑复制 → 手机轻点背面 → 粘贴。手机复制 → 同样轻点背面 → 电脑 Ctrl + V。

首次需手动创建系统快捷指令。本版没有一键导入包；复制下方说明不会自动安装指令。仅同步文字和网址，图片与文件请用“文件”页。

1. 电脑开启自动共享

在电脑的“剪贴板”页开启“自动共享电脑复制的文字”。需要常驻时，在设置中开启登录 Windows 后启动。

开启后，新的复制内容可能被已配对设备读取，包括敏感文字。

2. 创建“轻桥同步”快捷指令

  1. 在系统“快捷指令”中创建新指令，添加“获取剪贴板”。
  2. 添加“URL”，填入同步地址。
  3. 添加“获取 URL 内容”，方法 POST。添加头部 Authorization，值使用下方授权头。请求体选 JSON：文本字段 mode 填 smart；文本字段 text 选择第 1 步的“剪贴板”变量。将返回结果设为变量“同步结果”。
  4. 从“同步结果”获取词典值 copy，添加“如果”，条件为“真”。
  5. 在“如果”为真分支，从“同步结果”获取 text → “拷贝至剪贴板”。如果有“仅本地”选项，开启。只在这个分支拷贝。
  6. 在拷贝成功之后，从“同步结果”获取 receipt。再添加“获取 URL 内容”，使用下方确认地址，方法 POST、授权头相同，JSON 字段 receipt 选择取得的 receipt 变量。
  7. 结束“如果”。从“同步结果”获取 message，添加“显示通知”，内容选 message。熟悉后可删除通知操作。

两次请求共用的授权头

头部名称：Authorization。下方复制的值已包含 Bearer 和空格，仅放入自己的指令。

3. 绑定轻点背面

iPhone“设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下”，选择“轻桥同步”。

首次运行只初始化。之后在任一端复制新文字，再轻点背面测试一次。电脑需开机，并运行轻桥。

同步规则与限制

手机文字发生变化就发送，否则接收两分钟内的新电脑文字。两边都有变化时，本次手机文字优先。iPhone 不提供真实复制时间，无法严格按实际复制先后排序；重复复制相同文字也无法可靠识别。没有新内容时保留原剪贴板。

局域网入口适合日常快捷指令。使用固定 .local 地址可以减少 IP 变更影响；热点屏蔽 mDNS 时需要备用 IP，IP 改变后需更新指令。跨网临时地址到期后失效。

连不上、复制或传输失败
  • 先看页面顶部的原因，再点“重试连接”。若显示“互传已暂停”，在电脑恢复即可。
  • 同网连接时，两台设备应使用同一 Wi-Fi／热点，避免访客网络。检查 VPN 是否允许局域网。
  • Windows 防火墙提示时允许轻桥访问专用网络。无需关闭整个防火墙。
  • 浏览器不允许访问剪贴板时，可以长按预览复制、长按输入框粘贴，或使用快捷指令。
  • 文件发送中请保持页面前台。若提示“结果未确认”，先检查电脑接收记录，避免重复发送。
  • 点击下载只会交给浏览器处理。保存是否完成，请在浏览器下载列表查看。
旧版接口与手动同步模式

现有快捷指令继续兼容。可将智能指令的 mode 改为 receive，明确接收；改为 send，明确发送。

撤销后，本页和已配置的快捷指令都需要重新配对。
